#  GitHub Pages Test

Este repositorio contiene una página web estática sencilla, diseñada y desarrollada con el propósito principal de probar y demostrar la funcionalidad de despliegue continuo a través de **GitHub Pages**. 

Aunque es un proyecto de prueba, incluye una estructura semántica moderna y un formulario interactivo que pone en práctica diversos tipos de entradas y validaciones nativas de HTML5.

##  Características Principales

* **Estructura Semántica:** Uso de etiquetas HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) para un código limpio y accesible.
* **Formulario Completo:** Implementación de un formulario de captura de datos con múltiples tipos de `input` (texto, numérico, fechas, correo, botones de radio y selectores de color).
* **Estilos Personalizados:** Diseño responsivo y limpio utilizando CSS puro, implementando `Flexbox` para la alineación del formulario y variables de color básicas.
* **Despliegue Automático:** Configurado para estar en vivo y accesible en la web utilizando el servicio de alojamiento de GitHub Pages.

##  Tecnologías y Herramientas

* **Frontend:** HTML5, CSS3
* **Despliegue:** GitHub Pages
* **Control de Versiones:** Git & GitHub
